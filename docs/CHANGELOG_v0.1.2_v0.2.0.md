# 更新日志：v0.1.2 → v0.2.0

> 项目：research-agent
> 版本主题：检索专项 skills、质量控制、可视化看板与人工审核

## 一、检索专项 skills 与证据闭环

- 新增证据缺口反向检索，内容形成节点输出 `edge_gaps` 后自动回到知识消费/检索节点补强；
- 新增从首轮结果构造新检索式、参考文献/引文溯源两个受限 skill，仅用于单领域精深挖掘；
- 规划节点根据用户需求输出 `retrieval.strategy`，支持 `broad / evidence_gap / deep_single_domain`；
- 检索节点支持 `mode="skill"`，Europe PMC 客户端增加参考文献与被引接口；
- 专项检索全部带主题相关性门控和轮次/深度限制。

## 二、质量控制与领域词典全局归并

- 质量评估节点扩展为质量控制节点；
- 本体新增节点每满 300 个触发一次全局实体/关系归并；
- 以 IUPAC Gold Book 与 ChEBI 轻量本地词典提供外部身份，只合并同类型同词典身份的节点；
- 归并过程重指向边、合并重复关系、更新事件引用并写入 `merge_journal`。

## 三、可视化看板与人工审核

- 支持在 `data/*.db` 间切换数据库；
- 聚合展示数据构建节点与研究流程节点状态；
- 新增事件/日志过滤页；
- 新增规划节点交互页，可发送任务单或后台执行完整研究流程；
- 新增人工审核页，可提交预制或自定义审核结果，并查看审核历史。

## 四、其他

- NCPSSD 中文社科语料检索、入库、研究流程与报告支持；
- 人文社科领域画像；
- 本体规模与论文数量经验关系分析文档。

## 五、验证

- 全量测试通过：65 passed；
- 看板多库切换、节点状态、日志、规划接口、人工审核接口均有离线测试覆盖。
