## 4. 可用的经验公式

面向未来语料规模预算，可直接使用以下简化式：

```text
中文摘要/人文社科语料（N≥20）：
  nodes ≈ 3.4N，edges ≈ 3.2N

英文 OA 全文/化学科研语料（N≥20）：
  nodes ≈ 7.0N，edges ≈ 7.0N
```

更保守的区间形式：

```text
短文本/摘要类：
  nodes = (3.0 ~ 3.6)N
  edges = (2.8 ~ 3.3)N

全文科学文献类：
  nodes = (6.5 ~ 7.5)N
  edges = (6.3 ~ 7.2)N
```

冷启动阶段不宜套用：前 10-20 篇的实体重叠、主题聚焦度和首篇抽取产出会显著
影响截距，但斜率在 20 篇后趋于稳定。

## 5. 建议

1. 规模预算按“每篇新增实体/关系”估算法计算，不要按“LLM 每篇返回的
   entities/relations 数”累加；不同论文会出现大量共享概念和复用节点。
2. 全文比摘要的单位产量高约 1.9-2.1 倍。计划 500 篇时，全文语料可预算
   `nodes ≈ 3500，edges ≈ 3500`；纯摘要语料可预算
   `nodes ≈ 1700，edges ≈ 1600`。
3. 该线性经验式只在现有 1-320 篇观测区间成立；若继续扩充到数千篇，实体
   库和 schema 很可能出现“新类型、新概念增速放缓”的次线性阶段，届时应
   改用分段的 Heaps/饱和曲线重新拟合。
